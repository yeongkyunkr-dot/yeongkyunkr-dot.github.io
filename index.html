운영 체계

한 고객을 보는 데이터 축에서 AI까지

    접속(최근성) · 구매(이력·카테고리) · 관심사(탐색 상품) · 멤버십 상태 · 후기 감정 점수

    설치 → 가입 → 첫 구매 → 재구매 → 크로스셀·업셀 → 멤버십 → 이탈

    당월 접속 × 당월 구매로 활성·이탈 구분

    푸시 · 인앱 · 이메일 · 카카오톡 · 문자

03 생애주기 구간 정의와 구간별 캠페인 야놀자생애주기

CRM마케팅파트 리더 · 2022–2025

  • 구간 설치 → 가입 → 첫 구매 → 재구매 → 멤버십(골드) → 이탈
  • 기존 회원 관리 기준 당월 접속 여부 × 당월 구매 여부
구간대상·시점캠페인측정·결과
가입 유도설치 후 앱 온보딩 종료 시점인앱 메시지 + 첫 구매 쿠폰가입 전환율·구매 전환율. 미노출 대조군 대비 가입 전환율 상승
첫 구매 유도가입 후 1일·7일·14일첫 구매 쿠폰(매월 변경). 별도 예산 없이 운영구매 전환율
재구매구매 이력 회원, 관심사별(국내숙박·레저 등)관심사 기반 타겟 트리거CTR, 구매 전환율
크로스셀·업셀카테고리 조합별 대상. 예: 제주 숙박 예약 회원 → 레저, 모텔만 재구매하는 회원 → 유사 가격대 부티크 호텔, 국내숙박 → 항공·해외숙소팀 내 분석가가 만든 크로스 카테고리 대시보드로 조합 관리. 항공·해외숙소 X-sell 트리거 5종은 본인 기획·튜닝, 실행은 파트원항공·해외숙소 X-sell: 미발송 대조군 대비 항공 퍼널 유입 +133%~+305%, 항공 구매 전환율 +561%(인앱)
멤버십(골드)최근 1개월 30만 원 이상 또는 3회 이상 구매 → 1년 유지 (승급 조건은 멤버십팀 설계)6단계 캠페인 설계 → 04구매 전환율 미노출 대조군 대비 +35%
이탈당월 미접속·미구매 회원, 기간별 구간→ 06
  • 제휴·전사 캠페인 OTT·배달·카드 제휴(NOL 카드는 여신금융협회 심의 대응, 채널별 팀 분담 리드, 초도 발급 목표 초과), 시즌 기획전, 신규 카테고리 런칭 홍보
  • 채널 Paid = 카카오톡 / Owned = 푸시, 인앱, 이메일, 문자. 발송 빈도 푸시 > 인앱 > 카카오·문자 > 이메일. 최근성은 접속일 기준(여행은 구매 주기가 길어 접속일이 관심도를 반영)
역할파트 리드, 채널 총괄, 파트원 3~4명 도구Braze, SQL, Amplitude, Tableau
04 골드 클래스 멤버십 6단계 캠페인 설계 야놀자멤버십

2024년 2월 멤버십 론칭 · 설계 본인, 캠페인 실행 파트원

  • 배경 무료 멤버십 골드 클래스 론칭에 맞춰 인지부터 이탈 방어까지 캠페인 체계 필요
  • 제약 취소·쿠폰 사용·웹 활동은 앱 SDK 제약으로 Braze에 실시간 수집되지 않아 타겟 누락 발생
단계목적채널대상
1멤버십 제도 인지인앱(앱 실행·상품 상세 트리거)미인지 비회원
1.5멤버십 체험 유도인앱 + 푸시비회원, 특가 미구매

  • 데이터 보완 실시간 행동(앱 실행, 상품 상세)은 Braze 트리거로, 취소 제외 구매 건수·쿠폰 사용 여부는 DW에서 SQL로 일 단위 스냅샷을 만들어 CRM 툴에 배치 연동
  • 이탈 방어 이탈 임박 회원이 앱을 열면 코인 캐시백 리워드 모달 노출
  • 결과 구매 전환율 미노출 대조군 대비 +35%, 웰컴 쿠폰 다운로드율 리마인드 캠페인 전 대비 +300% 이상
05 발송 빈도 기준과 파트 운영 방식 야놀자운영 기준

대량 발송 요구와 개인화 트리거의 충돌 관리

발송 빈도 기준
  • 배경 경영진의 대량 발송 요구가 상시 있었고 개인화 트리거 캠페인과 충돌
기준내용
인당 발송 상한푸시 일 2회, 주 7회 미만
캠페인 태그유형(lifecycle / trigger / mass / 제휴) × 회원 구분(new / active / dormant) × 소재(motel / hotel / resort / leisure / abroad 등)
태그별 빈도 상한태그마다 차등, 트리거는 느슨하게
트리거 우선 보장Braze 빈도 제한 설정 + 발송 시각 분리
효과 측정처음 시도하는 캠페인은 모두 미노출·미발송 대조군 10%를 두고 비교
  • 결과 대량 발송 요구 속에서 자체 기준으로 발송량 제어, 트리거 캠페인 전환율 유지
파트 운영
  • 분담 세그먼트별(신규·기존·이탈) → 채널별(Paid·Owned) → 버티컬이 늘며 국내·해외별로 재편. 채널 캠페인 운영은 파트원에게 위임
  • 리더 역할 KPI를 전주·전월·전년 대비로 모니터링, 미진한 구간 리뷰 후 추가 캠페인 편성
  • 주간회의 성과가 좋은 캠페인과 부진한 캠페인 공유, 우수 사례 전파
06 이탈 예방·복귀: 오퍼 테스트와 경제성 분석 야놀자이탈 관리

구간 정의 → 오퍼 유형 테스트 → 경제성 분석 → 대상 재편

구간 정의와 오퍼 운영
  • 이탈 기준 두 가지: 당월 미접속, 당월 미구매
  • 미접속 구간: 2주 / 1개월 / 1개월 초과(2개월·6개월·1년)
  • 구간별 오퍼 차등: 활성 회원은 소액, 장기 이탈은 고액 쿠폰. 기간이 길수록 채널은 앱 밖으로
  • 발송 방식: 구간별 주기적 대량 발송, 미발송 대조군 유지
오퍼 유형 테스트 (코인 vs 쿠폰)
  • 설계 세그먼트 3종(첫 구매 대상 / 당월 미구매 / 제휴 포인트 연동 미구매) × 오퍼 2종(즉시 지급 코인 / 조건부 할인 쿠폰) × 채널 2종(푸시 / 인앱)
목적권장 오퍼근거
유입(CTR)코인푸시 CTR이 쿠폰보다 높음
구매 전환(CVR)쿠폰당월 구매자 CVR이 코인보다 높음

08 후기 감정 점수 기반 고객 케어 야놀자대조군 검증

데이터팀 NLP 점수 활용 · 2024년 4월 테스트 · 설계·첫 실행 본인, 이후 운영 파트원

  • 배경 개발자는 슬랙 채널로 저평점 리뷰를 검토, 마케팅은 평점 데이터 미활용. 저평점 리뷰 고객은 이탈 가능성이 높음(“앱 삭제하겠다” 류)
  • 데이터 데이터팀이 후기를 NLP로 분석해 만든 감성 점수(0~1) 테이블 확인. 담당자와 협의해 평균·최소·부정 비율 3축으로 4그룹 분류 기준을 조정
  • 실행 전일 후기 작성 고객을 매일 분류해 그룹별 메시지 발송(90%), 10%는 미발송 대조군. 그룹별 문구는 생성형 AI로 초안 작성
그룹분류 기준메시지
아주 긍정평균·최소 점수 0.9 이상, 부정 비율 0%만족 감사, 다음 여행 제안
긍정·중립평균 0.6 초과, 최소 0.5 초과후기 감사, 의견 반영 약속
부정·중립평균 0.6 이하, 부정 비율 0.1~0.2%후기 감사, 개선 약속

  • 결과 미발송 대조군 대비 앱 접속률 +68.8%, 구매회원 구매 전환율 +20.3%, 국내숙소 구매 전환율 +15.5%. 특히 아주 부정 그룹에서 재방문 차이가 통계적으로 유의
09 캠페인 운영에 쓴 생성형 AI 야놀자AI 활용

팀 GPTs, GPT 생성 콘텐츠

문구 A/B 테스트 결과를 팀 카피 GPT 작성 예시로 활용

  • 배경 대량 발송 캠페인 CTR 지속 하락
  • 대응 대상 고객 기준 세분화, 문구는 대조군을 둔 A/B 테스트로 비교
  • 사례 주간 호텔 추천 푸시. 호텔 이미지 소재는 도입 전후 비교로 클릭 상승을 확인한 뒤 기본 형식으로 확정, 이후 제목만 A/B 테스트
고정한 조건바꾼 조건
호텔 이미지, 오퍼제목 문구 (예: “주간 BEST 호텔 추천” / “놓치지 마세요 이번 주 핫플”)
  • 활용 유의한 차이를 보인 문구를 사례로 정리, 이 사례를 작성 예시(few-shot)로 넣은 카피 GPT 구축 후 팀 공용으로 사용
  • 측정 범위 카피 GPT의 CTR 기여는 별도 측정하지 않음
  • 그 밖의 팀 GPTs 팀 ChatGPT 도입, SQL 작성·리포트 작성용 GPTs 구축

해외 여행 코스 추천 메일 자동 생성

  • 배경 전략 카테고리인 해외여행, 앱 내 해외 상품 탐색 고객은 극소수
  • 대상 국내 고단가 호텔 탐색 고객을 해외 탐색으로 유도, 해외 탐색을 시작한 고객에게 특가·항공 프로모션
  • 콘텐츠 GPT로 국가별 여행 코스와 이미지를 자동 생성해 숙소·항공 정보와 함께 메일 구성
  • 결과 CRM 랜딩 전환율이 높게 나오며 해외마케팅팀이 먼저 협업 요청
